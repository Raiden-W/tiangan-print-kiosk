# 中英文触摸输入

昵称和出生地点共用 `NicknameKeyboard.jsx`，分别传入字段标签及 50 / 120 码点上限。`react-simple-keyboard` 和本地 Chinese 词典随包提供，不请求 CDN 或在线输入法。许可见 `public/KEYBOARD_LICENSES.txt`。

- 中文为单字全拼，ü 使用 v；候选翻页、空格选字、取消拼音。
- English 支持大小写，123 页提供数字符号；支持选区替换、光标移动、清空和完整字素退格。
- 只支持中英文两种语言，不增加独立数字键盘。实体键盘与系统 IME 可输入，组合结束后应用字符限制。
- 键盘宽 940 px、高 720 px，在 1080 × 1920 画布中央悬浮；FloatingPanel.jsx 管理居中、焦点及进退场，面板自身无滚动。面板与键帽为直角无装饰边框，轻阴影制造悬浮感。
- 自定义对话框限制焦点，背景表单 inert，完成或 Escape 收起。不使用浏览器顶层原生 dialog，避免相对于整个浏览器窗口定位。待选拼音未提交时提示先选字或取消拼音。
- 昵称与出生地的不同上限统一交给 shared/nickname.js。计数为 Unicode 码点，退格为完整字素。
- 出生日期及时间由 BirthPicker.jsx 提供：年月日或时分并排滚轮，原生触摸滑动、鼠标滚轮、可见选项点击和方向键均可选择，居中吸附后确认。调整年月时夹紧月末日期，年份范围为 1900 至当天，未来月份和日期不进入选项。
- 日期时间浮窗宽 860 px、高 670 px，同样居中。只有滚轮列内部可滚动，页面及浮窗外框保持固定。性别浮窗宽 700 px，提供男／女选择，无默认值；选中后退场并返回表单。
- 浮窗入场 220ms，遮罩 180ms；完成、取消或 Escape 触发 160ms 退场，完成后卸载并恢复焦点。测算期间背景表单不可操作。

样式入口：src/styles/keyboard.css 和 src/styles/pages.css。目标设备仅为 1080 × 1920，不再提供 390/800 横屏布局。触摸模拟及 DOM 几何检查不能代替一体机驱动和操作手感验收。

当前触摸约定：常用按钮与键帽至少 48px 宽、52px 高；取消拼音至少 44px 高，滚轮选项高 72px。页面禁止意外文本选中，编辑框保留文字选择。只有滚轮内部支持纵向滑动，页面与浮窗外框不滚动；功能不依赖 hover。触摸滑动和抬手均刷新 120 秒闲置计时，打印期间暂停闲置重置。
