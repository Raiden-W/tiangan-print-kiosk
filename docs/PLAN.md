## 打印实现约束

- 首选本地 HTML/CSS → 隐藏打印窗口 → Electron → 指定 Windows 打印驱动。厂商协议仅在实机证明必要时引入。
- 编号和打印由主进程负责。每次独立体验一个会话，首次打印时分配核销号；同一会话的失败重试复用同一个号码。
- 暂建议 24 位安全随机数字字符串，以最终纸宽、DPI 和外部扫描格式为准。不能把完整编号转换为 JavaScript Number。
- 在 userData 中先成功持久化记录，再提交打印；本地查重和排他创建记录，冲突时重试。跨离线设备属于概率性唯一；如需严格多机唯一，再确认设备号或号段。
- 记录仅含会话 ID、核销号、时间、版本、状态和尝试次数；不默认保存姓名、生日或完整表单。此方案不承诺跨重启恢复完整个人凭证。
- Code 128 的编码值与可读编号来自同一个规范字符串，保留前导零。实际扫码结果必须与编号逐字一致。
- 主进程串行处理，并对重复点击去重。打印状态区分准备、提交中、已提交、明确失败和结果不明。
- 打印接口成功不等于实物已经出纸。断电、崩溃或超时后的不明任务不得自动重放，交由现场人员确认。
- 结果页显示反馈，不增加业务页面；打印期间暂停普通闲置重置，改用独立打印超时。旧会话回调不得更新新会话页面。
- 开发预览使用测试标记，与正式核销凭证区分。不预先搭建核销后端、账户或核销状态管理。
