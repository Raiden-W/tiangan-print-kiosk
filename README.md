# Tiangan Print Kiosk

Electron + React + Vite + JavaScript 的 Windows 触摸屏娱乐互动应用，固定画布 **1080 × 1920**。四页流程：欢迎 → 信息填写 → 五行结果 → 小票与打印状态。四页使用提供的正式 PNG、Misto 和叶子工厂罡风宋，按对位图还原完整内容与版式。

## 启动

使用 Node.js 24、提交的 npm 锁文件：

```sh
npm ci
npm run dev           # Vite + Electron；真实 AI 与打印使用此入口
npm run dev:web       # 浏览器固定演示，http://127.0.0.1:5173
npm run dev:electron  # Vite + Electron，关闭窗口会停止开发服务
npm run build
npm run preview       # 生产浏览器预览，http://127.0.0.1:4173
npm start             # Electron 加载 dist/
npm run start:kiosk   # 全屏 Kiosk
```

当前机器若没有全局 npm，可使用 `.tools/bin/npm.cmd`；该目录仅为本机忽略工具。浏览器检查请设置视口 1080 × 1920，其他尺寸未提供适配；页面、键盘和浮窗外框不滚动，日期时间滚轮内部支持触摸滑动。生产预览重新构建后需要刷新旧标签页。

桌面开发时保留启动终端：它会输出 Electron 窗口、页面加载及 React 启动状态。如果显示已有桌面实例，请先关闭旧窗口及其开发终端再重新启动；如果窗口白屏，终端中的 `[dev]` 启动错误可用于排查。

## DeepSeek 配置

本地开发复制 `.env.example` 为 `.env`，填写自己的 `DEEPSEEK_API_KEY`，然后重新启动 Electron。`.env` 被 Git 忽略；主进程只在未打包模式读取它。打包应用从启动环境读取 `DEEPSEEK_API_KEY` 和可选的 `DEEPSEEK_MODEL`。不要使用 `VITE_` 前缀、把真实密钥发到聊天或提交到仓库。

- 默认模型 `deepseek-flash`，官方地址 `https://api.deepseek.com/chat/completions`。
- 关闭思考、temperature=0、max_tokens=500、JSON 对象、非流式、30 秒超时，不自动重试。
- 昵称、性别、出生日期、时间和地点会在提交时发给 DeepSeek；应用不将参与者表单写入日志、文件或浏览器存储。供应商的数据处理政策独立于本应用。
- 日主天干只按输入的公历年月日推算，不进行 UTC、时区、真太阳时或跨日修正；性别、时间与地点用于五行娱乐估算，昵称不参与计算。
- 全球地点不明确时由 AI 猜测最可能地点继续估算，不新增地点选择或确认步骤。
- 固定版本 Prompt 位于 `shared/analysis.js`。结果校验日干枚举及五项 0–100 整数，合计必须为 100；空回复、截断和非法数据不展示、不打印。
- 校验后保留 AI 返回的五行百分比，包括日主元素并非最高的情况。结果页直接显示这五项数值；结果快照不改写比例。
- 低温度不保证重复调用完全一致；不增加跨会话缓存。更换模型或 Prompt 版本后应重新核对公开样例。

浏览器标签标题标明“离线演示预览”，使用固定辛金及五行比例，不调用 AI 或打印机，完全离线可用。正式画布不显示开发提示。Electron 缺少密钥时明确报错，不静默使用演示数据。

## 输入与会话

昵称、性别、公历日期、小时、分钟、自由文本出生地全部必填。性别通过居中浮窗选择男／女，无默认值；昵称上限 50 个 Unicode 码点，地点上限 120。日期范围 1900-01-01 至设备当天。中英文字键盘支持拼音选字、英文大小写及数字符号。所有浮窗在画布中央显示，日期时间采用支持触摸和鼠标的滚轮，见 [键盘说明](docs/KEYBOARD.md)。

参与者表单、AI 结果和小票快照只在内存中。返回首页、完成、120 秒闲置或刷新后清理；待完成请求会取消，旧回调不能写入新会话。打印进行时暂停普通闲置重置。打印请求只提交主进程生成的结果 ID，票面来自同一份已校验快照，不重新测算。

`content/fortune.json` 保存十天干中英文以及 `meanings.甲` 至 `meanings.癸` 十段各不相同的寓意。乙、丙、己、辛、癸沿用原有五行文案；甲、丁、戊、庚、壬为可编辑的新文案。按天干修改对应 `meanings.<天干>`，用 `\n` 指定换行，修改后重启生效；建议保持三行左右，修改内容时同步更新 `version`。旧版按五行存储的配置需要更新为此结构。

- 桌面开发：启动时读取仓库 `content/fortune.json`。
- Windows 安装版：读取安装目录 `resources/content/fortune.json`，文件位于 `app.asar` 外，可直接编辑；打包时通过 `extraResources` 提供。
- 浏览器开发：启动页面时读取同源 `/content/fortune.json`；构建时输出独立 `dist/content/fortune.json`。修改源文件后重新构建并刷新生产预览，或直接编辑已部署的 JSON 后刷新。
- 配置缺失、JSON 损坏或必要内容不完整时明确提示，不回退占位文字。配置不会编译进前端 JS；主进程与参与者数据的加载入口相互独立。

测算等待使用整页五行环转动效；日主名称对应的图标显示后以 2 秒周期呼吸高亮，图标下方标注“日主”，百分比继续显示 AI 原值。页面、按钮和浮窗使用短淡变及轻位移，退出动画结束后卸载。

## 打印与打包

点击 P03 的 PRINT THE RECEIPT 后进入 P04，桌面程序向 `POS58 Printer` 提交一次打印。屏幕与纸票共用内容组件，纸票按有效 48 mm 宽度排版（纸卷 58 mm）；实体票底部横线后有 5 mm 空白占位块，不额外打印标记。占位块不出现在屏幕纸票中；实体票保留原有 5 mm 底部内边距，纸长按渲染高度加 3 mm 余量计算。无条码及测试文案，票面图标为黑色，打印前等待字体和图标解码完成。实际走纸与裁切位置由打印机驱动设置控制。

P04 初始露出 24px 不规则纸张下边缘，进入页面后等待 0.7 秒，再匀速吐纸 3 秒，停在设计图版式。每次进入只播放一次，状态更新不重播；动画不代表实体出纸成功，不参与物理打印。无法读取打印机列表与未找到目标打印机分别提示，浏览器仅作屏幕预览。

主进程在提交前写入 `userData/print-jobs` 最小记录，仅含任务 ID、时间、内容和 Prompt 版本、状态及尝试次数，不含姓名、生日、地点或 AI 原文。旧打印记录不读取、不迁移。提交成功不代表实体出纸；不明任务不会自动重打。详见 [打印说明](docs/PRINT_TEST.md)。

```sh
npm run lint
npm test
npm run build
npm run pack:win  # Windows x64 本地目录
npm run dist:win  # Windows x64 NSIS 安装包
```

安装包默认 Kiosk；开发窗口支持 F12 / Ctrl+Shift+I。Windows 的 Alt+F4 可退出本地预览。打包前关闭同目录程序以免文件占用。云端/Linux 可运行浏览器、测试和构建；Windows Electron、安装包和打印驱动须本机验证。不自动推送或发布。

在 Windows x64 上执行 `npm ci` 和 `npm run dist:win` 后，从 `release/` 取 `Tiangan Print Kiosk Setup 0.1.0.exe`，复制到目标电脑安装。目标电脑无需 Node.js；需联网访问 DeepSeek，并安装、连接名为 `POS58 Printer` 的打印机驱动（名称忽略空格及大小写）。

安装版不会读取开发目录的 `.env`。在目标电脑的 Windows“环境变量”中新增当前用户变量 `DEEPSEEK_API_KEY`，值为自己的密钥；可选设置 `DEEPSEEK_MODEL`，不设置使用 `deepseek-flash`。配置后注销并重新登录 Windows，再启动应用，使桌面快捷方式继承新变量。不要将密钥打进安装包或提交到仓库。寓意文案可在安装目录 `resources/content/fortune.json` 中修改，重启应用生效。

## 验证边界

测试覆盖性别校验与传递、比例保护、外部配置重读、AI 响应校验、异常、取消、会话隔离、输入、日期、快照与打印去重。当前 UI 更新使用本地模拟检查页面，未调用真实 AI、未提交实体打印、未生成新安装包；历史与本轮记录见 [验证记录](docs/VERIFICATION.md)。

触摸交互通过浏览器触摸事件检查：按钮、拼音选字、性别浮窗及日期滚轮原生手势均可操作。键帽和辅助按钮扩大触控区域，无功能依赖鼠标悬停。P04 仅保留“返回首页”；120 秒闲置重置仍保留，触摸滑动也刷新计时，打印期间暂停。
